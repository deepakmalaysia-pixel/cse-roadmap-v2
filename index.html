Why Year 1-2 defines whether a CSE student gets a job in Year 4

This is not a course list. This is a mentorship operating system. It solves 3 problems you face daily as a mentor: (1) Students chase languages without foundation, (2) Final year panic without career clarity, (3) Passed-out students with no tracking of what they actually completed.

What this contains

  • Fishbone Diagram (Ishikawa) for Y1-Y2: 4 bones - Programming Logic, CS Core (DSA/DBMS/OS/CN), Math & Logic, Engineering Habits. These are root causes of unemployability if weak.
  • Flowchart for Y3-Y4: 6 career tracks with Indian market demand, fresher & mid-level salary bands, skills semester-wise, 2 projects per track, certifications, target companies (Product vs Service vs Corporate).
  • Recovery Plan: 90-day fast-track for passed-out job seekers - SQL + Cloud + One Track.
  • Progress Tracker: Student can check off tasks, Supabase stores it, mentor can see cohort.

The Philosophy

Foundation = Employability, Specialization = Salary Multiplier. Data from India Skills Report 2026: CSE employability 80%, B.Tech overall 71.5% - highest in 5 years. Freshers 3.5-7 LPA, average 9-15 LPA, with Bangalore/Hyd/Pune 20-30% premium. Product companies pay higher starting, but Corporate Digitization (banks, manufacturing, retail computerising systems) has massive volume and stability.

This tool intentionally delays Python vs Java choice to Year 3. Year 1-2 is language-agnostic problem solving + SQL + Linux.

How to use - For Mentors & For Students

🎓 If you are a 1st/2nd Year Student

  1. Open Roadmap → Fishbone. Ignore career tracks for now.
  2. For each bone, check off sub-tasks in My Progress. Example: C Language = Pointers + Memory + File handling done?
  3. Rule: Don't jump to React/AI until you finish SQL + DSA + Linux basics. Track weekly streak.
  4. Goal by end of 2nd year: 2 projects + GitHub with 100+ commits + 100 DSA patterns + SQL 50 problems.

💼 If you are 3rd/4th Year

  1. Open Flowchart, filter by interest: SaaS vs Corporate vs Fast Entry.
  2. Pick ONE track. Don't do 3 tracks parallely. See semester-wise skills (Sem5-8).
  3. Build the 2 projects listed for that track - deploy on cloud, add to progress tracker.
  4. Take the certification listed, update resume with metrics.

🔄 If you are Passed-Out & Job Seeking

  1. Don't restart 4 years. Go to Recovery Plan in Roadmap section.
  2. Day 1-30: SQL + Aptitude (becomes screenable)
  3. Day 31-60: Cloud + Git + Docker (becomes deployable)
  4. Day 61-90: One Track + 2 Projects (becomes hirable). Enterprise IT & QA/SDET fastest entry.

👨‍🏫 If you are a Mentor

  1. Use Intro as classroom presentation (first 20 mins).
  2. Give students link to Vercel deployment. Ask them to create account in My Progress (Supabase Auth).
  3. Monitor cohort via Supabase Table view or add a Mentor Dashboard (see sql/ schema).
  4. Weekly: ask for progress % screenshot.
